# Dataset

Questa directory ospita i dataset utilizzati per la calibrazione e per la stima di posa.

## Contenuto atteso

- `images/`: raccolte di immagini (`.png`, `.jpg`) provenienti dalle sessioni di acquisizione o calibrazione.
- File `.npz`: archivi NumPy con annotazioni, coordinate o dati derivati.
- Eventuali file ausiliari (`.json`, `.yaml`) con metadati o parametri di cattura.

I dataset non sono versionati nel repository. Scaricali dalle fonti fornite dal progetto e copiali qui mantenendo questa struttura.
